# Open-Source Visayas Grid Model Simulator

An open-source power system simulator for the Visayas Grid, built with [Pandapower](https://www.pandapower.org/) and [Dear PyGui](https://github.com/hoffstadt/DearPyGui). Designed as an accessible platform for power system studies in the Philippine context.

## Features
- AC Power Flow using the Newton-Raphson method
- AC Optimal Power Flow with Locational Marginal Pricing (LMP)
- Network modification via CSV upload
- Line outage contingency simulation
- Interactive geographic map and Single-Line Diagram (SLD)
- Baseline vs. modified run comparison

## Getting Started
1. Download `Open Source Visayas Grid Model Simulator.exe` from this repository.
2. Place the `.exe` inside an empty folder. Running it will generate HTML files for the map and SLD in the same directory.
3. Double-click the `.exe` to launch. No Python installation or additional dependencies required.
4. For detailed instructions on installation, features, and usage, please refer to the **Open-Source Visayas Grid Model User Manual.pdf** included in this repository.
